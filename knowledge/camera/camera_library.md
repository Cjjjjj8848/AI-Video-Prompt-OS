# 镜头语言库（camera）

> 景别 / 机位 / 构图 / 焦段的镜头 DNA。

## 1. 景别体系

| 景别 | 画面范围 | 带货用途 |
|---|---|---|
| 远景/全景 | 全身/环境 | 场景建立、开场 |
| 中景 | 腰部以上 | 人物互动、演示 |
| 近景 | 胸部以上 | 表情、口播 |
| 特写 | 局部/产品细节 | 产品质感、动作细节 |
| 微距 | 极近 | 材质、纹理、膏体等 |

## 2. 机位

- 平视：真实、口播、UGC 感
- 俯视 45°：产品展示、桌面操作
- 顶视 90°：开箱、平铺展示
- 仰视：力量感、气场
- POV：第一人称代入

## 3. 构图原则

- 产品主体放三分位或中心对称（电商）
- 留白控制：信息流缩略图需主体突出
- 多产品/多元素用对角线或网格构图

## 4. 焦段

- 广角（24-35mm）：环境+人物，UGC 随手拍感
- 标准（50mm）：真实自然
- 长焦（85mm+）：特写压缩、产品质感
