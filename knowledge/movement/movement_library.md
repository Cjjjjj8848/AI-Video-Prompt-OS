# 运镜库（movement）

> 镜头运动 DNA：推拉摇移、POV、环绕、航拍等。

## 常用运镜

| 运镜 | 效果 | 带货用途 |
|---|---|---|
| 推近 | 聚焦主体 | 产品亮相、细节 |
| 拉远 | 建立环境 | 场景开场 |
| 摇镜 | 扫视空间 | 多产品/多场景 |
| 移镜 | 平行跟随 | 产品移动、使用过程 |
| 环绕 | 360° 展示 | 产品全方位亮相 |
| 手持微晃 | 真实 UGC 感 | 真人口播、开箱 |
| POV 推进 | 第一人称代入 | 使用场景 |
| 甩镜（Whip） | 动感、快切 | 开场、节奏 |
| 航拍/俯冲 | 空间感 | 户外/大场景 |
| 跟镜 | 跟随主体 | 人物动作 |

## 使用原则

- 简单品少运镜、靠画面本身；复杂品用运镜带出结构
- 每镜一种主运镜，避免"推拉摇移"堆叠
- POV 镜与产品特写交替，增强代入与质感
- 转场处运镜方向保持连贯（运动方向一致更顺滑）

## 缓急静缓运镜节奏曲线（DNA-017，来自 case_001）

四镜短视频的运镜节奏编排：

| 镜号 | 运镜 | 速度 | 情绪 |
|---|---|---|---|
| Shot1 | Tilt-UP（向上倾斜） | 缓 | 悬疑、期待 |
| Shot2 | Fast Zoom-in（极速冲入）+ Whip-tilt Down（极速下甩） | 急 | 紧张、惊吓 |
| Shot3 | Locked-off（固定俯拍） | 静 | 释然、专注产品 |
| Shot4 | Tilt-UP + Smooth Glide Out（平滑滑出） | 缓 | 欢快、释放 |

**核心规则**：
- 极速运镜（Fast Zoom / Whip）后必须接静止镜头（Locked-off），形成强烈反差
- 缓→急→静→缓的节奏曲线对应情绪的悬疑→紧张→释然→欢快
- 每镜只一种主运镜，不堆叠
- 甩镜转场必须带自然运动模糊（1/50s-1/100s 快门）
