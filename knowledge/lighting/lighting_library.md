# 灯光与氛围库（lighting）

> 灯光/色调/氛围 DNA。

## 1. 电商/带货常用灯光

| 灯光方案 | 效果 | 适用 |
|---|---|---|
| 窗边自然光+环形补光 | 真实、通透 | UGC/美妆/个护 |
| 柔光箱主光+反光板 | 无硬阴影、高级 | 产品展示 |
| 侧光 | 立体感、质感 | 服饰、饰品 |
| 逆光轮廓 | 氛围、高级感 | 品牌片 |
| 顶光桌面 | 操作场景 | 美食、手工 |

## 2. 色调氛围

- 清透粉白：美妆/疗愈
- 暖黄复古：家居/美食
- 冷灰高级：数码/男性用品
- 高饱和活力：快消/食品

## 3. 规则

- 灯光描述具体可执行，禁止"自然光"空泛
- 产品主色调为唯一事实，灯光不得造成颜色漂移（见 product_consistency.md）
- 前后对比镜头：两段光照保持一致，保证对比有效
