# 转场与衔接库（transition）

> 段内转场 DNA。V5 融合基线。

## 1. 常用转场

| 转场 | 做法 | 适用 |
|---|---|---|
| 匹配剪辑 | 上一镜运动/形状与下一镜衔接 | 产品与使用场景切换 |
| 物体遮挡 | 物体扫过镜头完成过渡 | 展示型视频 |
| 甩镜/快速摇镜 | 动势掩盖剪辑点 | 快节奏带货 |
| 闪白/闪黑 | 情绪切换、时间跳跃 | 前后对比 |
| 缩放/推拉 | 从局部到整体 | 产品亮相 |
| 无转场硬切 | 景别/机位差异足够时直接切 | 高频节奏 |

## 2. 转场使用原则

- 转场处运镜方向保持连贯（运动方向一致更顺滑）
- 简单品少转场、靠画面本身；复杂品用转场带出结构
- 每镜一种主运镜，避免"推拉摇移"堆叠
- 转场服务于节奏，不为花哨而加

## 甩镜转场+声音桥组合（DNA-018，来自 case_001）

POV 视频最自然的视角切换方式：

**做法**：
1. 前一镜结尾做 Whip-tilt Down（极速下甩），带自然运动模糊
2. 同时播放"呼啸声+风声"连贯两镜
3. 后一镜开头突然平稳定格（Locked-off），视角已切换
4. 前一镜结尾的情绪音（如悬疑低音）延续到后一镜开头（声音桥）

**为什么有效**：
- 运动模糊掩盖剪辑点，观众感觉是连续动作而非切换
- 声音桥让听觉连续，进一步掩盖剪辑
- 甩镜后的突然静止形成反差，增强下一镜冲击力

**适用场景**：
- POV 第一人称视频的视角切换
- 从"看别人"切换到"看自己的手"（如充电宝案例从仰视小丑切换到俯拍手部）
- 长视频分段拼接
- 快节奏短视频的镜间过渡
